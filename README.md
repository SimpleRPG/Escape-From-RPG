# Escape From RPG

2DエクストラクションRPGのスマホ向けプロトタイプ。

## 現在の機能

- 仮想スティックによる360度移動
- 長押し時のコピー・選択・コンテキストメニュー抑止
- Pointer Events / pointer capture
- 探索開始ごとのランダムマップ生成
- ランダム配置される建物
- 建物の外から内部を非表示
- 建物へ入ると内部を表示
- 屋内アイテム
- 敵AI
- 近接攻撃
- 素手
- ナイフ
- 鉄パイプ
- 軽装アーマー
- 防護ベスト
- 防具によるダメージ軽減
- 回復薬
- 戦利品
- 脱出地点
- localStorageによる端末内保存
- マップSeed表示

## 操作

スマートフォン:

- 左下の仮想スティックをドラッグして移動
- 右側の攻撃ボタンで攻撃
- スティックから指を離すと停止

PC:

- WASD / 矢印キー
- Spaceで攻撃

## ゲームループ

拠点
→ ランダムマップ生成
→ 探索
→ 建物へ侵入
→ アイテム回収
→ 敵との戦闘/回避
→ 脱出
→ 戦利品を拠点へ持ち帰る
