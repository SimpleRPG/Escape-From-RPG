# Escape From RPG

銃をまだ実装しない、2DエクストラクションRPGの最初のプレイアブルプロトタイプです。

## 現在の内容

- ブラウザで動作
- スマートフォン向け移動ボタン
- 1人プレイ・オフライン
- 拠点
- 探索開始
- 2D探索マップ
- プレイヤー移動
- 障害物
- 敵の追跡AI
- 接触ダメージ
- HP
- アイテム回収
- 戦利品
- 脱出地点
- 脱出成功 / 探索失敗
- localStorageによる端末内セーブ

## 今後

## ファイル構成

必要なプロトタイプファイルはすべてリポジトリのルート直下に置ける構成です。
